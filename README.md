# StudioNamma Clone

A frontend website clone inspired by the StudioNamma website, built to practice modern web development concepts, responsive design, animations, and interactive user interfaces.

## 📂 About the Project

This project is a frontend recreation inspired by the design and user experience of the StudioNamma website. The main goal of this project was to improve my frontend development skills by working with layouts, animations, responsiveness, and interactive UI elements.

---

## ✨ Features

* Responsive user interface
* Modern website layout
* Interactive UI elements
* Smooth animations and transitions
* Responsive design for different screen sizes
* Clean and organized frontend structure
* Interactive navigation and components

---

## 🛠️ Tech Stack

* **HTML5** – Website structure
* **CSS3** – Styling, layouts, animations, and responsiveness
* **JavaScript** – Interactivity and dynamic functionality

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/studionamma-clone.git
```

2. Navigate to the project folder:

```bash
cd studionamma-clone
```

3. Open the project using VS Code.

4. Open `index.html` directly in your browser or use the **Live Server** extension.
